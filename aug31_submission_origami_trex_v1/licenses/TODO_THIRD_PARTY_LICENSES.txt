container_submission.md §1 requires third-party license notices in the image.
Not generated here -- license text should come from the actual installed
packages, not be typed from memory. Before building the final image:

  pip install pip-licenses
  pip-licenses --with-license-file --format=plain-vertical \
      --output-file THIRD_PARTY_LICENSES.txt

run inside the built image (or an identical venv) against
requirements-inference.lock plus torch/torchvision, covering at minimum:

  torch, torchvision, transformers, tokenizers, huggingface-hub,
  safetensors, numpy, pillow, opencv-python-headless, timm,
  eclipse-zenoh, msgpack

T-Rex itself (qwen_vla/, tactile_vqvae/) is Apache-2.0 (see
origami_trex/T-Rex/pyproject.toml) -- include its LICENSE file too.

Replace this file with the generated THIRD_PARTY_LICENSES.txt.
